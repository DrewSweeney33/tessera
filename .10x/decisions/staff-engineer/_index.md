# Staff Engineer Index

## Cross-cutting principles

- Greenfield repo: conventions in `tessera-v1.md` are the standard until superseded.
- One source of truth for each concern (schema, Markdown rendering, time, config, logging, error mapping).
- Layer rules are enforced by lint, not by review.
- A task is done when `npm run verify` passes and behavior is tested and documented.
- Accessibility and keyboard operation are requirements, not polish.
- Exact version pins, license check, audit in CI.
