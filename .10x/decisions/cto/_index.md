# CTO Index

## Cross-cutting principles

- Build only what serves the Claude round trip. Everything else is optional.
- No recurring cost, no external services, no model calls inside the app.
- Prefer MIT or Apache dependencies. The app itself is AGPL-3.0.
- Pin versions, isolate third-party algorithms behind our own interface.
- Re-check the competitor landscape at milestones M2 and M3.
