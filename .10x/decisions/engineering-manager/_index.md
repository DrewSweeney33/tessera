# Engineering Manager Index

## Cross-cutting principles

- Tasks are half a day or less. Oversized tasks are split before starting, not stretched.
- Rolling-wave planning: detail the next two milestones, outline the rest, re-plan at each gate.
- Every milestone ends with an exit gate that writes state files before work continues.
- CI and the container build come early because Docker cannot be tested locally.
- The checkpoint after M2 is a planned decision point, not a surprise.
- Outward-facing actions (GitHub remote, publishing images, tags) need the owner's approval.
