# Product Manager Index

## Cross-cutting principles

- The Claude round trip is the product. Features that do not serve it wait.
- Import errors are a user experience, not an afterthought. Claude must be able to fix them.
- Never lose review history. Updating content never resets progress.
- Single user, no accounts. Do not add multi-user concepts to v1 screens or schema.
- GitHub stars are not a metric. Personal use and a working quickstart are.
